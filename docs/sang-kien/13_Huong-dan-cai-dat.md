# II. HƯỚNG DẪN CÀI ĐẶT

## 1. Cài đặt trên Windows

1. Tải file cài đặt (.exe) về máy tính.
2. Chạy file vừa tải.
3. Làm theo hướng dẫn hiển thị trên màn hình (bấm Next → Install) để hoàn tất.
4. Sau khi cài đặt xong, có thể mở ứng dụng qua shortcut xuất hiện trên Start Menu hoặc màn hình Desktop.

## 2. Cài đặt trên Android

1. Tải file cài đặt (.apk) về điện thoại/máy tính bảng.
2. Nếu hệ thống yêu cầu, bật quyền "Cài đặt ứng dụng từ nguồn không xác định" cho trình duyệt/ứng dụng quản lý file đang dùng để tải.
3. Mở file .apk vừa tải để tiến hành cài đặt.

## 3. Cài đặt trên iOS

Do đặc thù chính sách quản lý ứng dụng của Apple, việc cài đặt trên thiết bị iOS (iPhone/iPad) cần thực hiện theo một trong hai cách sau:

- **Phát hành chính thức qua App Store**: khi đã đủ điều kiện đăng ký tài khoản nhà phát triển Apple, ứng dụng được phát hành chính thức và người dùng cài đặt trực tiếp qua App Store như các ứng dụng thông thường khác.
- **Cài đặt thử nghiệm trực tiếp**: trong giai đoạn thử nghiệm chưa phát hành chính thức, có thể cài đặt trực tiếp lên thiết bị cá nhân thông qua công cụ hỗ trợ cài đặt dành riêng cho thiết bị iOS.

## 4. Yêu cầu cấu hình tối thiểu

- **Windows**: từ Windows 10 trở lên.
- **Android**: từ Android 8 trở lên.
- **iOS**: từ iOS 16 trở lên.
- **Dung lượng trống**: tối thiểu khoảng 200-300MB tuỳ nền tảng, do dữ liệu từ điển được đóng gói sẵn cùng ứng dụng để bảo đảm hoạt động ngoại tuyến hoàn toàn.
